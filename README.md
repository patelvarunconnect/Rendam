# 📊 Product Review Sentiment Analysis

A **machine learning** web app that reads customer reviews and classifies them as **positive** or
**negative**. Analyse a single review, or upload a **CSV of thousands of reviews** and get charts,
a results table and a downloadable report.

Built with **Python**, **scikit-learn**, **Pandas**, **Plotly** and **Streamlit**.
**No API key needed** — the model runs on your computer.

## ✨ Features

- ✍️ **Single review** — sentiment, emoji result card and confidence gauge
- 📁 **Bulk analysis** — upload any CSV, pick the text column, see sentiment share, confidence chart and
  a results table; download the results as CSV
- 📈 **Model performance** — accuracy, precision, recall, confusion matrix and per-class scores
- 🔄 **Retrain** with one click after changing the dataset

## 🧠 Model

| Step | Choice |
|---|---|
| Text features | TF-IDF on single words and 2-word phrases (so "not good" is understood) |
| Classifier | Logistic Regression |
| Evaluation | 80/20 stratified train-test split |

## 📦 Dataset

`data/reviews.csv` is a **sample dataset generated by `generate_data.py`** so the project runs out of
the box. For real-world results, replace it with a larger labelled dataset (for example Amazon or
Flipkart product reviews from Kaggle) with two columns:

```
review,sentiment
"Battery life is great",positive
"Stopped working in a week",negative
```

Then click **Retrain model** in the sidebar (or run `python train.py`).

## 🚀 Run it locally

**Windows:** double-click `run.bat`

**Any OS:**
```bash
python -m venv .venv
.venv\Scripts\activate        # Mac/Linux: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

The app opens at <http://localhost:8501>. The model trains automatically on first run.
